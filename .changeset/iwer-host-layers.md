Host mode: WebXR Layers quad and cylinder layers. `XRWebGLBinding.createQuadLayer` / `createCylinderLayer` (layouts `mono`, `stereo`, `stereo-left-right`, `stereo-top-bottom`; `texture` and `texture-array`; `isStatic`, `clearOnAccess`) give each layer a host swapchain of its own (`XRHostBackend.beginSwapchain` with `options.layer`, answered with an `id`), and `getSubImage(layer, frame, eye)` returns the view's sub-image with the layer texture the host provides (`getLayerColorTexture`). `XRQuadLayer` and `XRCylinderLayer` keep `space`, `transform` (a copy of the one given), their shape, `blendTextureSourceAlpha` (true by default, as in Chromium and the Layers polyfill) and `needsRedraw` (false once the frame the layer was drawn in is over; a static layer can be drawn whole in that frame); `destroy()` calls `releaseSwapchain`. A mono `texture-array` layer asks the host for a one-layer texture array (`options.textureType`). Once per frame the host receives the session's layer list in `renderState.layers` order (`submitLayers`): each layer's pose in the base space (or the viewer space for a head-locked layer), its shape (a quad's full size: WebXR's `width`/`height` are half-extents, as in Quest Browser) and whether the page drew it. Emulated sessions are unchanged.
